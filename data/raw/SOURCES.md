# Data sources

All files from Baseball Savant (MLB Advanced Media), 2026 regular season. Files in this folder are never edited.

| Project file name | Original download name | What it is | Downloaded |
|---|---|---|---|
| vesia_pitches_2026.csv | savant_data-6.csv | Every Vesia pitch (Statcast Search, pitcher 681911) | 2026-11-08 |
| yesavage_pitches_2026.csv | savant_data-8.csv | Every Yesavage pitch (Statcast Search, pitcher 702056) | 2026-11-09 |
| lb_splitters_2026.csv | savant_data-7.csv | League splitters, one row per pitcher (Statcast Search, Split-Finger, grouped by player) | 2026-11-09 |
| lb_pitch_arsenals_2026.csv | pitch_arsenals.csv | Leaderboards > Pitch Arsenals (average velocity) | 2026-11-08 |
| lb_active_spin_2026.csv | active-spin.csv | Leaderboards > Active Spin | 2026-11-08 |
| lb_arm_angles_2026.csv | pitcher_arm_angles.csv | Leaderboards > Pitcher Arm Angles | 2026-11-08 |
| lb_spin_direction_ff_2026.csv | spin-direction-pitches.csv | Leaderboards > Spin Direction, four-seamers | 2026-11-08 |
| lb_spin_direction_fs_2026.csv | spin-direction-pitches-2.csv | Leaderboards > Spin Direction, splitters | 2026-11-09 |
| lb_spin_direction_ch_sl_2026.csv | (to download) | Leaderboards > Spin Direction, changeups and sliders | |
